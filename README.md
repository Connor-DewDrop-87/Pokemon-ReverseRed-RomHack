# Pokemon-ReverseRed-RomHack
A Modified Version of Pokemon Fire Red where the Order of the Gyms have been Reversed. This includes changed Teams, Rebalanced Pokemon, and Changes to the Map to allow or prevent Progression. All 151 Pokemon are available, with most of the Johto Dex being available. New Items have been added to allow for the evolution of Trade Evolutions, aswell as Johto Evolutions and pre-evolutions being available. Minor changes to the story have been made to justify the changes to the progression of the Player and the Characters.
